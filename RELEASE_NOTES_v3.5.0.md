# Worldwalker RPG 3.5.0

## Canon-character consistency

- Yahiko now begins one day before the original Akatsuki is founded instead of on his death date.
- His founding and death events are separated by the intended narrative period.
- Canon starts normalize name, age, background, mentor, location, faction, rank, standing, companions, skills, titles, stats, pools, and timeline.
- Canon identity and mechanics are protected from contradictory opening-narrator patches.
- Yahiko begins as Akatsuki Founder and Leader with Nagato and Konan as companions, Jiraiya as mentor, and positive Akatsuki/Amegakure standing.
- Factions no longer appear as unknown people in Relationships.

## Character creation

- Guaranteed hidden classes are created automatically from broader phrases such as "guaranteed hidden crafting class."
- A concealed class still has a complete internal true name, feature, affinities, bonuses, limits, clues, reveal requirements, and advancement path.
- Player-facing concealed names reflect the prompt theme without revealing the true internal identity.
- Backstories no longer use exposed assembly labels or the phrases "Raised around" and "Their own account adds."
- Common starter skills use concrete, readable descriptions.
- Worlds without authored start-option lists now show explicit default era and location choices.
- Hidden-class reroll wording changes to a setting-appropriate secret path or potential outside literal class worlds.
- Ordinary 1.00x "Typical local potential" summaries are hidden.

## Turns, rolls, and Chronicle

- Empty Moment advances preserve the complete prior standing plan and continue its remaining actions in order.
- Every d100 result is displayed beside its exact action.
- Duplicate terminal punctuation is normalized.
- How To Play now correctly describes contextual d100 checks.
- A successful opening retry removes the earlier setup notice and hides Retry Opening.
- The live retry cleanup now safely handles all Chronicle entries without a browser error.

## Tactical challenges

- Tactical rounds now use scene-specific decisions for archives/infiltration, duels, dungeons, negotiations, and crafting.
- Archive examples include disguise, rooftop entry, bribery, inner-watch tactics, and objective extraction.
- Each choice retains visible payoff and uncertainty while describing what the character actually does.
