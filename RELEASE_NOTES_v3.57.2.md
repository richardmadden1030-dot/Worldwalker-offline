# Worldwalker RPG v3.57.2 — The Approved Living Map

This corrective release replaces the interim map renderer with the approved Living Map prototype implementation.

## What players will notice

- The map is once again the dominant center stage, with the character rail on the left, inspector on the right, and Chronicle/action dock below.
- Zoom is semantic again: World, Regional, and Local levels reveal different countries, villages, landmarks, missions, events, and eligible people.
- The center map uses all available width between open panels instead of leaving unnecessary blank gutters.
- The active campaign—not demo state—feeds the map, and actions chosen from the map return to the main game for resolution.
