# Worldwalker RPG v3.27.0

## Jujutsu Kaisen depth

- Generated Innate Techniques now form one coherent package: rule, applications, limits, counters, growth, and Domain all describe the same power.
- Added persistent development for reinforcement, technique mastery, barriers, Reverse Cursed Technique, Maximum Techniques, Domains, and Heavenly Restrictions.
- Added durable binding vows, witnessed-technique intelligence, Black Flash records and “in the zone” state, official grade evidence, clan obligations, sentient-curse growth, and soul/possession records.
- Added role-specific opening missions and a clearer expandable JJK journal.
- Added optimized scenes for a cursed hospital, subway tunnel, clan estate, and Domain interior.

## Playtest fixes

- Long skips now process every recurring-finance cycle instead of stopping after 240 payments.
- Partial recurring-finance updates preserve the existing schedule and transaction type.
- Finance labels differing only by punctuation no longer create duplicate entries.
- Mobile modal headers now stay opaque while scrolling, keeping preview text readable.
- Queued actions now show useful action types instead of marking ordinary training as uncertain.
- Technique-witness records are initialized and retained correctly.
- JJK creation now calls its linked origin/location choice “Starting Placement,” and ordinary field supplies no longer appear as a weapon.
- Campaign previews now label numerical values as “Starting attributes” instead of “Open-ended starting abilities.”

## Verification

- 606 automated tests pass across campaign creation, simulation, progression, persistence, multiplayer, UI contracts, and world-specific systems.
- Manual mobile-browser checks covered startup, Bleach character creation, high-spiritual-pressure stat scaling, expandable Shikai/Bankai cards, action entry, time controls, and Chronicle layout.
- Deterministic multi-turn playtests covered Naruto, Bleach, One Piece, Overgeared, and Solo Max-Level Newbie.
