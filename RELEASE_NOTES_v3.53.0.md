# Worldwalker RPG v3.53.0 — Campaign Arc Director

- Established quests, standing instructions, repeated development and nemeses can become optional multi-turn campaign arcs.
- Arcs advance only when a player action, NPC plan or recorded world event actually touches them.
- Every arc exposes multiple plausible approaches without imposing an objective order.
- Explicit resolutions record how the arc ended and preserve a concise epilogue.
- Resolved arcs create a quiet aftermath for recovery, relationships, training and ordinary life.
- Existing campaigns initialize the new records automatically.
- Arc discovery, relevance, pacing, closure and history run locally without an additional AI request.
