# Worldwalker RPG v3.44.2

## Combat Applications and Clearer Campaign Updates

- Named moves described inside a broader skill now appear as individual combat choices.
- Nested moves inherit their parent ability's bonuses, costs, and restrictions.
- Older combat-oriented skills are repaired when legacy metadata incorrectly marked them as utility-only.
- Incoming NPC messages now require a believable sender, connection, and reason to know the news.
- Famous canon characters use explicit world-scale Advisor benchmarks instead of generic low-confidence fallbacks.
- Existing malformed messenger notifications are cleaned automatically when a campaign loads.
- Assignment updates no longer repeat the same objective under several labels.
- Empty directions and generic "no danger" filler are hidden from the Chronicle and Journal.
- Combat application selection and update cleanup are covered by new regression tests.
