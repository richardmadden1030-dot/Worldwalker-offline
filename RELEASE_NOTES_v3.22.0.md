# Worldwalker RPG v3.22.0

## Jujutsu Kaisen world

- Added Tokyo and Kyoto Jujutsu High starts for first, second and third years, plus Independent Curse User, Great Clan Member and Sentient Cursed Spirit starts.
- Added playable Yuji, Gojo, Yuta, Megumi and Maki canon starts and four starting eras.
- Every original character receives exactly one exclusive birth slot: an Innate Cursed Technique or Heavenly Restriction.
- Added a strong-technique/restriction guarantee and selectable cursed-spirit starting grade.
- Original techniques use the background when possible and otherwise generate a coherent setting-valid rule, applications, limits and growth path.
- Technique applications are ordinary trainable skills; Heavenly Restriction mechanically changes physical and cursed-energy stats.
- Sentient curses receive a generated nature and exponential feeding growth based on a victim's cursed energy.
- Added JJK grades, binding-vow/barrier/domain progression, lore guidance, faction rules and world-specific GM instructions.
- Added a full-screen Black Flash lightning effect.
- Added JJK interface styling, portrait direction, three scene backgrounds and a world map.

## Bleach repair

- Characters who already possess Shikai or Bankai no longer remain stuck with an unnamed Zanpakutō. Existing saves recover the name from their release profile, Shikai status or learned Shikai skill when possible.
