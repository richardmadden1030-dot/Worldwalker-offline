# Worldwalker RPG v3.16.2

## Bundled world soundtracks

- Adds seven default Bleach tracks to the portable `music/Bleach` directory.
- Adds four default Naruto tracks to the portable `music/Naruto` directory.
- Includes both soundtracks in the Windows and phone-host packages.
- Keeps every track at its supplied quality instead of applying another lossy MP3 conversion.
- Preserves the existing music-folder workflow, so players can add more tracks and refresh the player normally.
