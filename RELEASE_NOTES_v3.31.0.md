# Worldwalker RPG 3.31.0

This release turns the phone layout into a purpose-built companion interface
without removing information from the desktop game.

- Added permanent mobile navigation for Chronicle, Actions, Character, World,
  and More.
- Added a compact, horizontally scrollable status ribbon for health, world
  energy, conditions, time, danger, and combat round.
- Added a sticky time/Advance dock that remains reachable above the browser and
  keyboard and reports the number of queued actions.
- Rebuilt mobile action entry with a growing composer, persistent drafts,
  queue collapse/clear, duplicate, reorder, edit, remove, and touch gestures.
- Added full-screen mobile layouts for the Advisor, Journal, map, Party,
  Quests, Relationships, Inventory, and related world-progression pages.
- Added Chronicle filters for Story, Combat, World, and Growth, collapsible
  routine details, lazy rendering, and per-campaign scroll restoration.
- Added a dedicated combat dock for Attack, Defend, Ability, Item, Flee, and
  Nonlethal controls, including the existing bonus-turn flow.
- Improved the phone map with a larger touch surface and a readable landmark
  information sheet.
- Added low-data, haptic-feedback, and large-text controls, plus reduced-motion
  support, offline/reconnect feedback, unsent-action warnings, and improved PWA
  caching and installation behavior.
- Advisor questions can now estimate any named character using current NPC
  condition, narrative feats, relationships, rank, faction, and canon baseline.
  Missing exact numeric stats no longer causes a refusal or a player-only
  answer.
- Nine-Tails and other tailed-beast chakra cloaks now count as active visual
  transformations during normal Advance turns. They receive a transformed
  portrait cache key and return to the normal portrait when deactivated.

Desktop layout and save schema 19 remain unchanged.
