# Worldwalker RPG v3.37.2

- Requesting, proposing, or arranging a duel no longer begins combat before the other participant accepts and the fight actually starts.
- “With a deep bow” can no longer be parsed as an opponent named Deep Bow.
- Canon identity, office, faction, crew, squad, and role records now ground GM/lore/Advisor context across all eight built-in canon worlds.
- Unambiguous Bleach captain/lieutenant division swaps are corrected locally; Tōsen is the 9th Division captain and Aizen the 5th at the affected campaign date.
- Existing saves retain their Chronicle history and receive a correction note when a known old assignment error is detected.
- Concealed class clues now use clear wording such as “Unidentified Hidden Class — Flash affinity”; the game retains a complete, properly named internal class package until it is discovered.
