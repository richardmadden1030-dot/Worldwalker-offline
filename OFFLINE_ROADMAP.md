# Worldwalker Offline — Remaining Roadmap

Build 0.5 is no longer only the original three-system prototype. It now includes the main offline RPG loop: contextual roleplay actions, Storylets, procedural quests, world-native progression, powers/forms, combat, companions, exploration, equipment/crafting, hidden conditions, rewards, expeditions, factions/world pressure, Atlas/Journal/Character surfaces and local saves.

## Highest-value remaining upgrades

1. **Full tactical-grid parity** — the current offline combat is a reliable range-lane system. Port the richer grid geometry, terrain interactions and multi-unit objectives from mature Worldwalker next.
2. **Branching expeditions** — expeditions are persistent and multi-stage, but their route is still mostly linear. Add node maps, optional rooms, shortcuts, treasure choices, hazards and alternate exits.
3. **Deeper systemic NPC interaction** — relationships already unlock training, help and companions. Add request/persuasion/gift/command/confide/rivalry interfaces with more NPC-specific authored profiles.
4. **Larger canon-event library** — current world pressure and setting events work fully offline, but do not yet equal the online project's full canon timeline/intervention depth.
5. **Richer Living Atlas presentation** — the offline Atlas is interactive and functional, but not yet the full illustrated/semantic-zoom Living Map presentation.
6. **Organizations/property/legacy parity** — factions and companions exist; the deepest organization delegation, property, family/life and legacy features from current Worldwalker still need dedicated offline ports.
7. **More deterministic content packs** — modular power names and Storylets already vary offline, but a hundred-hour campaign will benefit from much larger per-world decks, quest chains, bosses, locations and ability components.

The architectural rule remains strict: **systems establish facts first; UI/Chronicle display those facts; no language model is needed to decide what happened.**
