# Worldwalker RPG 3.0.0

Version 3.0 turns unusual character backgrounds into complete starting mechanics and ships as a fresh Windows release.

## Character creation

- Hidden-class requests now create a named, world-appropriate class or path with a description, class feature, limitation, advancement route, signature skill, stat bonuses, and a sustained-learning modifier.
- Original characters have a small chance to receive a rare starting ability or hidden class even when the background does not explicitly request one.
- Explicit ability and hidden-class requests are guaranteed and can coexist.
- Canon-character starts do not receive random non-canon additions.
- Starting classes persist in campaign state and appear in the character summary, Skills journal, status window, and Power Summary.

## Presentation

- Campaign creation now uses natural labels such as **Starting Ability**, **Starting Loadout**, and **Background**.
- Skill descriptions no longer explain that they were generated from player input.
- Internal prompt-source metadata is no longer placed in skill descriptions.

## Rolls

- Every time-skip check records its own action index and action text.
- Multiple checks no longer inherit the final queued action's label.
- Chronicle roll details identify the exact action each d100 result resolved.

## Release identity

- App version: 3.0.0
- Save schema: 7
- Windows executable file metadata: 3.0.0.0
