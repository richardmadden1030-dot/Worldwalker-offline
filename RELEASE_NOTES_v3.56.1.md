# Worldwalker RPG v3.56.1 — One Battlefield Per World

- Naruto, One Piece and Bleach now use the tactical battlefield exclusively.
- The retired combat panel no longer flashes or remains available in those worlds.
- Legacy combat action and mercy endpoints reject attempts to bypass the tactical board.
- Existing saves already inside a battle are migrated into tactical combat automatically.
- Worlds without a completed tactical implementation retain their current combat system.
