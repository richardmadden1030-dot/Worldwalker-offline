# Worldwalker RPG v3.19.0

## Full Satisfy class fantasy

- Overgeared now treats crafting as one optional career instead of the default.
- Character creation includes martial, magic, healing, support, summoning,
  companion, command, social, exploration, merchant, production, and hybrid
  archetypes with role-appropriate stats, gear, and starting expertise.
- Original classes use the complete canon class-name catalog and its full range
  of class families as private design precedent. The AI must create a distinct
  identity, features, signature skill, restrictions, quests, advancement, and
  specializations rather than copying a canon class or merely reskinning one.
- Hidden-class fallbacks now cover combat, magic, support/social, companions,
  and production-combat paths.
- Any meaningful class-aligned activity can advance class development—not only
  crafting or actions containing the word “class.”
- The Satisfy status window now foregrounds class type and role development.
  Production paths, mastery, orders, and standing remain hidden until the
  character genuinely pursues a production profession.
- Default Overgeared ambient effects now use neutral MMO motes; forge embers
  appear when the scene or current activity actually involves crafting.

No save-schema change was required.
