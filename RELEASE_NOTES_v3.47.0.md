# Worldwalker RPG v3.47.0 — Crews, Command Chains & Lasting Legacies

- **World-specific group rosters:** Pirate Crew / Marine Squad, Ninja Squad / Shinobi Organization, Hunter Team, Guild, Raid Party, Nation & Retainers, Division, Sorcerer Team and Company. Existing world themes are preserved. See the group name, every established member, positions and combat power without a proximity filter. Unknown power stays unassessed; estimates are labeled.
- **Organizational command chains:** Leaders, deputies, reporting lines and units inform commands. Independent allies remain independent. Departed members and applicants cannot be commanded as active subordinates.
- **Independent NPC development:** Ongoing training uses actual elapsed time, existing attributes, discipline, known mentors and established accelerated methods. Noncombat expertise does not inflate combat power. Repeated updates do not double-award training; NPCs are not scaled to the player.
- **Narrative recruitment and departure:** Invitations, accepted membership, terms, roles, loyalty reasons, absence, retirement and departure are stored. Former members and candidates have separate expandable lists. Stale nearby-party data cannot quietly undo a departure.
- **Family and organizational succession:** Family, apprentices, mentors, known ages and world-appropriate aging modes persist. An accepted heir succeeds a leader only after recorded death or explicit retirement. No forced retirement, inherited mastery or automatic player-character replacement.
- **Old-save and mobile support:** Existing membership migrates automatically. More opens the world-specific roster on phones; long names and descriptions wrap. Existing combination abilities remain available.

These mechanics reuse the existing GM turn and chat requests. Local roster, aging and training calculations add no separate AI calls; relevant group context adds some prompt text.

This release does not add a new operations/mission engine, a new team-combat system, or changes to the separate offline prototype.

## Installation

Extract the complete Windows or Phone-Host ZIP into a new folder. Existing user data stays in its normal location. For Phone-Host, run **Start Phone Mode.bat** on the PC. Hosted deployments must restart/redeploy from `web_prod` before the website serves this version.
