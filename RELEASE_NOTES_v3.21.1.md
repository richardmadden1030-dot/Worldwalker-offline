# Worldwalker RPG v3.21.1

## Zanpakutō preview rerolls

- Original Bleach characters now receive a coherent Zanpakutō concept in the
  campaign preview, including spirit, inner world, Shikai, Bankai, limitations,
  costs, and counters.
- A **Zanpakutō abilities** button rerolls only that concept while preserving
  the character's stats, background, equipment, and other starting choices.
- Locally generated concepts have alternate identities and mechanics, while a
  configured AI is explicitly told to create a genuinely different reroll.
- A dormant preview does not grant Shikai or Bankai. Releases remain unachieved
  unless the creation background says the character already possesses them.
- If Shikai or Bankai is explicitly owned, rerolling replaces the corresponding
  mechanical release skills without changing the character's ownership stage.

Save schema remains 17.
