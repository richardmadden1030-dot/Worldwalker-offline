# Worldwalker RPG v3.58.0 — The Map Becomes the World

This release turns the approved Living Map composition into the normal game layout instead of treating it as a separate map screen.

## What players will notice

- The active world map fills the center of the game, with the Chronicle directly beneath it.
- Current-location artwork and its label now sit on the right above Action Chat and time controls.
- Each campaign loads only its own atlas, borders, factions and landmarks. One Piece, Bleach, HxH and the other worlds can no longer inherit Naruto map data.
- Smooth pan, semantic zoom, political ownership, routes and eligible moving character pieces remain available.
- Characters are shown as live map pieces only when they have a meaningful relationship, are a nemesis, or share the player's tracked group.
- Mobile has a dedicated Map tab; the Actions tab keeps the location scene and action controls together.
- Bleach realm switching, custom locations and narrative territory changes still use the active campaign's real state.
- Existing character panels, Chronicle, messages, action entry, time advancement and world systems remain accessible.

No new map locations or timeline dates were added in this release.
